# Linked List for Priority Task Management

## Project Description
This project is designed to manage tasks based on their priority using a Singly Linked List data structure. It helps users organize tasks and complete important tasks first.

## Features
- Create new tasks
- Insert tasks based on priority
- Delete tasks
- Search for tasks
- Update task details
- Display all tasks

## Technologies Used
- C++
- Data Structures
- Singly Linked List

## Project Objective
To understand linked list operations and implement an efficient priority-based task management system.

## Conclusion
This project demonstrates the practical application of linked lists in task management and improves understanding of data structure concepts.
